## 1. 프로젝트 개요 및 배경

### 현실의 문제점 (Pain Point)

현재 아파트 단지의 음식물 쓰레기 배출 방식(RFID 포함)은 주민이 직접 비닐봉지나 개인 용기를 열어 오물을 쏟아부어야 합니다. 손에 국물이 묻거나 악취가 배는 등 비위생적이고 번거로운 가사 노동입니다.

### 프로젝트 목표

주민이 전용 수거통을 거치하기만 하면, 협동로봇이 자동으로 통을 파지하여 RFID 수거함에 배출하고 물 세척까지 완료하여 돌려주는 **'손에 묻지 않는 24시 스마트 무인 수거 시스템'** 을 구축합니다.

## 2. 시스템 아키텍처 및 기술 스택

대중성, 상업성, 기술적 깊이를 모두 만족하기 위해 3개 레이어가 유기적으로 연동됩니다.

| 레이어 | 기술 | 역할 |
|---|---|---|
| **Front-end** | React | 아파트 무인 키오스크 및 사용자 화면. 로봇 공정 상태(배출 중 / 세척 중)와 F/T 센서 기반 실시간 하중 데이터를 그래프 대시보드로 시각화 |
| **Back-end** | FastAPI | 주민 인증 및 RFID 장비 개폐 인터페이스 연동. 배출 유형(일반 / 강한 흔들기)에 따른 ROS2 서비스 큐 관리 및 데이터 로깅 |
| **Robotics** | ROS2 · 두산 협동로봇 | GP_05 평행 그리퍼 제어. 말단 F/T(Force/Torque) 센서 데이터 실시간 구독 후 조건부 시퀀스 제어 |

## 3. 공정별 상세 로봇 제어 시퀀스

덤핑 강도에 따라 **유형 1(일반 배출)** 과 **유형 2(강한 흔들기 배출)** 2가지 모드로 분리 수행됩니다.

### 3.1 배출 및 덤핑 단계

| 단계 | 동작 | 상세 |
|---|---|---|
| 1. Pick | 파지 | 주민이 V자형 물리 가이드 거치대에 통을 놓으면, 로봇이 고정 좌표의 테두리를 강력 압착 파지 |
| 2. Move | 이동 | RFID 수거함 문 열림 신호와 연동하여 배출 위치로 이동 |
| 3. Tilt | 기울임 | 내용물 배출을 위한 관절 기울임 — **유형 1: 45° / 유형 2: 60°** |
| 4. Shake | 흔들기 | 고점도 쓰레기 탈락을 위한 왕복 궤적 제어 — **유형 1: 진폭 5 강도 × 8회 / 유형 2: 진폭 8 강도 × 10회** |
| 5. Dump & Return | 배출 완료 및 복귀 | 음식물이 쏟아질 때 말단 무게가 급감하는 **'Force Drop' 현상을 F/T 센서로 실시간 감지**. 빈 통 무게 도달 확인 시 즉시 원위치 복귀하여 시간 효율 극대화 |

### 3.2 세척 단계 (Washing Process)

| 단계 | 동작 | 상세 |
|---|---|---|
| 1. Move & Set on Stand | 지그 안착 | 세척 위치로 이동하여 세척 가이드 스탠드에 통을 안전하게 거치 |
| 2. Water In | 물 받기 | 수도꼭지를 열어 2초간 급수. **F/T 센서로 수직 하중 Fz 정상 증가 여부를 체크하여 단수·고장 실시간 예외 처리** |
| 3. Shake | 물 세척 | 그리퍼로 통을 다시 잡아 진폭 5 강도 × 8회 흔들어 내부 오염물 세척 |
| 4. Water Out | 물 버리기 | 통을 완전히 뒤집어 배수구에 배수 후, F/T 센서로 잔여 수량 재확인 |
| 5. Return & Home | 복귀 | 최초 주민 투입 위치로 이동하여 안전 하강 후 `Complete` |

## 4. 기대효과 및 상업성

- **B2B / B2G 시장성** — 아파트 건설사의 프리미엄 주거 옵션 상품 및 지자체 친환경 스마트시티 조달 장비로 도입 가능
- **주거 가치 향상** — 음식물 쓰레기 배출 과정의 비위생적 요소를 원천 차단하여 주민 만족도 극대화
- **유지보수 비용 절감** — 통 규격 불일치 예외 상황을 소프트웨어(무게별 모드 자동 전환)와 범용 테두리 파지 하드웨어로 해결하여 고장률 및 세팅 비용 절감

| ID | 내용 |
|---|---|
| BR-01 | 아파트 단지 내 비위생적인 음식물 쓰레기 배출 프로세스의 100% 무인 자동화 |
| BR-02 | 세척 서비스 일체화를 통한 고부가가치 리테일 및 구독형 주거 가전 모델 구축 |

| ID | 내용 |
|---|---|

| SR-02 | 모바일 QR 스캔 및 키오스크 연동을 위한 웹서버–로봇 간 실시간 이기종 통신 아키텍처 수립 |

| ID | 항목 | 검증 내용 |

| TC-01 | 홈 이동 테스트 | 시스템 초기 전원 인가 및 예외 상황 강제 종료 후, 로봇팔이 주변 구조물과 충돌 없이 안전 좌표인 홈(Home) 위치로 정확히 복귀하는지 검증 |
| TC-02 | 픽업 테스트 | GP_05 그리퍼가 고정 거치대 위 수거통의 상단 외경 테두리(Rim)를 조준하여, 논슬립 패드의 마찰력으로 이격 없이 들어 올리는지 검증 |
| TC-03 | 모드 분기 테스트 | HMI 화면에서 일반 배출 버튼 → `mode 1` 시퀀스, 강한 흔들기 버튼 → `mode 2` 시퀀스가 정상 트리거되어 동작이 분기되는지 검증 |
